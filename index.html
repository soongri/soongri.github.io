가사와 코드 입력

가사 앞에 대괄호로 코드를 입력하세요. 예: [C]오늘도 [G]함께 걸어가요. 한 줄에 코드를 여러 개 넣을 수 있습니다.

코드 표기는 C, Am, F#m, Bb, G7, Dsus4처럼 입력할 수 있습니다. 키 변경은 코드 이름만 바꾸고 가사는 유지합니다.
